# GPM CORE — Static Executive Experience

A standalone HTML/CSS/JavaScript executive prototype based on the supplied GPM CORE specification and reference screens.

## Run locally
Open `index.html` in a browser. No server or dependencies are required.

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save. GitHub will provide the public Pages URL.

## Note
This is the static executive experience. The data is demo/simulated data from the project prototype; it is not connected to a live ERP.
